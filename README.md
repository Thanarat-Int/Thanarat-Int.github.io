# Thanarat C. — Personal Portfolio

> Personal portfolio website of **Thanarat Chuephasuk (กอล์ฟ)** — Applied AI Engineer.
> Live site: **https://thanarat-int.github.io/**

---

## 🎯 Purpose

This website was created as a **personal portfolio to support job applications**. Its goal is
to present — clearly and professionally — who I am, the skills I have, and the projects I have
built, so that recruiters and hiring teams can quickly understand my background and reach out.

It focuses on my work as an **Applied AI Engineer / AI Automation Engineer**, covering real,
hands-on projects in AI applications, RAG systems, dashboards, and workflow automation.

## ✨ Features

- **Cinematic intro gate** with an animated, responsive landing screen.
- **Experience timeline, skills, projects, education, and certificates** sections.
- **Babata AI** — an on-page assistant that answers questions about me
  (skills, projects, experience, education, goals, contact). Runs fully client-side.
- **Fully responsive** — adapts automatically to phones, tablets, laptops, and large displays.
- Downloadable up-to-date **résumé (PDF)**.

## 🛠 Tech Stack

- **HTML5**, **CSS3** (custom + **Tailwind CSS**)
- **Vanilla JavaScript** (no framework, no backend)
- **Canvas** animations, **Swiper.js** for the certificates carousel
- Hosted on **GitHub Pages**

## 📁 Structure

```
├── index.html          # Main page
├── css/style.css       # Styles + responsive rules
├── js/main.js          # Interactions + Babata AI engine
├── data/               # profile.json, knowledge.md (Babata AI knowledge base)
├── img/ , assets/      # Images, logos, résumé
└── favicon.svg
```
